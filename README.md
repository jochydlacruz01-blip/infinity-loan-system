# INFINITY LOAN SYSTEM

Sistema profesional de gestión de préstamos y cobranzas.

## Aplicación Android
- Kotlin
- Jetpack Compose
- Arquitectura MVVM
- Soporte multimoneda: DOP, USD y EUR
- Perfiles: administrador, supervisor, cajero y cobrador

## Proyecto
Desarrollo desde cero de una aplicación Android profesional.
